# Timberborn Trainer v0.3.0

中文游戏内修改工具，支持 **Windows 64位 Steam Timberborn 1.1.2.8-ffc2de0-sw**（Unity 6000.5.11f1）。使用官方Mod加载器，无需其他Mod或BepInEx。

## 功能

- 地图选中已完工单物品仓库，自动读取原生存储配置并增加/减少物品；空仓库已配置物品时也可使用。
- 独立科研入口，读取、增加、减少和设置科研点数。
- “立即完成所有建造”一次性批量完工；之后的新工地不会自动完成，保留原版建筑暂停及阻挡规则。
- 饥饿与口渴独立维持基础需求正常满值，关闭后恢复原更新状态；其他营养需求不锁定，已开始的动作不强行取消。
- 本周期已选干旱/恶水总时长编辑（实验）：1～1000整数天，不是剩余时间，不切换天气或控制未来周期。
- JSON配置保存、读取、导入、导出及恢复默认。

## 下载与安装

下载附件 **TimberbornTrainer-v0.3.0-win64.zip**，不要使用GitHub自动生成的Source code作为安装包。

1. 退出游戏并备份重要存档。
2. 解压整个TimberbornTrainer文件夹至实际“文档”目录下的 `Timberborn/Mods/`（可能由OneDrive重定向）。
3. 检查 `Timberborn/Mods/TimberbornTrainer/manifest.json` 与DLL同层，避免嵌套及同Mod ID重复安装。
4. 在官方Mod管理器启用“海狸修改工具”，进入聚居地后打开“修改工具”，按需开启全局开关。

库存与灾害时长编辑需要手动暂停游戏。完整操作、卸载及FAQ见[中文使用说明](https://github.com/crayonmmn/TimberbornTrainer/blob/v0.3.0/docs/使用说明.md)。
