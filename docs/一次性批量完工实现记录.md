## 实现与范围

建造页按钮和功能说明统一为“立即完成所有建造”。删除原 ConstructionRules/ConstructionEngine 及 BuildingModule 的 Tick、工时计算和 IncreaseBuildTime 路径，取消两个建造开关。没有新后台任务、持久队列、自动重试或 Harmony。

点击且全局启用、精确版本匹配时，ConstructionCommands 取得一次实体数组快照。逐项检查原生实体存活/初始化状态、EntityRegistry.GetEntity 的同一对象引用、ConstructionSite、BlockObject 未完工状态及库存有效性。建筑自身 IsOn 为假时统计受阻，不解除暂停。调用前再次检查，每个快照实体最多一次 FinishNow。没有全局游戏速度限制。

原生 FinishNow 负责材料补足和完工链，本项目不手工填充库存、不标记完成、不修改物流、携带物品或预留。受阻的调用可能已补足原生施工材料/进度并随后按原版机制完成，统计仅代表本次观察，不自动追踪或重试。

只有调用正常返回且原生 IsFinished 或对应 BlockObject 的 EnteredFinishedStateEvent 得到确认时计完成。临时事件观察者只在该次调用期间注册，finally 注销；用于完工后直接删除的特殊工地，不把实体消失本身作为成功。调用/注销异常保守记异常，即使可能已经生效也不重试/回滚。正常返回但仍未完工计受阻；无状态证据计未确认。单项异常不影响后续工地；场景/全局状态失效停止剩余操作。

BuildingModule 仅保留场景内最近统计，Unload 释放场景服务与结果；执行中保护阻止重入。普通 UI 刷新只读结果和按钮可用状态，不调用命令。
