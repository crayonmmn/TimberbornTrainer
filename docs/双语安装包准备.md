# 中英文独立安装包与仓库准备（2026-11-15）

## 最终方案

用户已纠正为两个独立安装包：不实现运行时语言切换，不新增语言按钮、事件订阅或持久化字段。此前仅整理翻译资源，未引入运行时切换实现；可复用资源已保留为UI/Localization/strings.en.json。

中文源码仍是唯一业务实现。build/Build.ps1与Test.ps1支持-Language en或zh-CN，默认en。Compiler.ps1通过Roslyn解析字符串字面量，仅在编译内存文本中将资源表命中的token替换为英文，绝不修改源文件、标识符、成员/API名字或表达式结构。运行时没有翻译服务、语言判断、字符串扫描或额外依赖。

资源表覆盖当前Core/Modules/UI中465个含中文的唯一字面量，并统一9个标点/格式片段。包括三个模块标题、按钮、提示、配置错误、库存角色/预留/诊断、兼容性警告及动态消息片段。英文构建替换532处字面量；中文构建替换0处。动态数值、原生物品ID及游戏本地化提供的名称不经过替换；游戏自身文本和第三方异常详情不是本Mod翻译范围。

中文保持原有文案；共享ActionButton仅增加换行和收缩样式以容纳英文，没有改鼠标/键盘事件。所有Core、Modules文件及三个窗口/标签实现与本轮开始时哈希一致。无语言切换或窗口重建。

## 包与仓库

两种构建输出到dist/en/TimberbornTrainer和dist/zh-CN/TimberbornTrainer。相同Mod ID TimberbornTrainer.Core、Version0.3.0、AssemblyVersion0.3.0.0、MinimumGameVersion1.1.2.8和空依赖。仅英文manifest名称/介绍本地化。只能安装其中一个包，不能共装或混用DLL。

每包10个文件：TimberbornTrainer.dll、manifest.json、README.md、README.zh-CN.md、LICENSE、THIRD_PARTY_NOTICES.md、PACKAGE-LANGUAGE.txt，以及docs下Usage.en.md、使用说明.md、第三方代码来源记录.md。不包含游戏DLL、测试、缓存、日志或个人配置。双语ZIP只在新的本地PreparedPackages目录生成，不覆盖历史v0.3.0发行包。当前使用现有版本号准备构建，不创建新标签或宣称已公开发布；未来正式发布版本号应另行确定。

README.md改为英文默认首页，README.zh-CN.md为中文入口；新增英文完整使用说明及双语Release说明草稿。LICENSE与第三方声明不改法律文本。保留AI开发与AS IS/无维护承诺说明。
