# 第四、第五阶段开发记录

日期：2026 年 11 月 7 日。版本：0.2.0.0。许可证：MIT。

## 实现

- 原有 C# UI Toolkit 面板调整为深背景、浅文字；按钮显式边框及正常/悬停/按下/禁用状态，输入框焦点边框。
- 面板移至左侧避开右下提示；模块入口横向排列，底部固定保存、读取、恢复默认与关闭，导入导出折叠，长路径仅悬停显示。
- 五个模块显示未实现、已启用、已禁用、运行异常。资源管理只启用科研，库存明确标注未实现，其他四个模块不启用。
- ResourceModule 通过构造注入 ScienceService；适配器仅访问 SciencePoints、AddPoints(int)、SubtractPoints(int)。没有 Harmony、反射写入或私有字段修改。
- 独立 ScienceCommands 处理输入、版本/全局门控、余额、总量与溢出校验、命令结果和真实回读。
- 输入限制 0～十亿整数，拒绝负数、小数、指数表达式及非法字符；减少超余额不截断，直接拒绝。
- 设置目标根据真实余额计算差额；零增减与相同目标不调用写入接口；不自动重试失败调用。
- 结果显示修改前、实际变化、修改后与成功/失败；接口异常或回读不符不伪造成功。
- 科研目标和增减输入不写入配置；SchemaVersion 仍为 1，原有配置实现未改动。
- 恢复默认、导入与读取不会回滚或执行一次性科研命令。正常获取科研机制未打补丁。

| 要求 | 实机结果 |
|---|---|
| 正常读取 | 新局科研为 0，Trainer 与游戏顶栏一致 |

| 负数 | 输入 -1 被拒绝，点数仍为 250 |
| 非法数值 | 输入 abc 被拒绝，点数仍为 250 |
| 超范围 | 输入 1000000001 被拒绝，点数仍为 250 |
| 全局关闭 | 初始关闭时点击默认增加 100 的禁用按钮，点数保持 0；恢复默认后按钮再次禁用 |
| 真实同步 | 成功操作均同时对照原生顶栏、ScienceService 回读与操作反馈；并非仅更新本 Mod 显示 |

## UI 验收

- 标题、正文、导航按钮和输入文字可读；边框清楚，悬停与禁用状态可辨，输入框获得焦点后边框变亮。

- 运行异常状态没有在游戏中故意注入故障；相关接口异常、回读失败和不符分支使用模拟接口测试。
- 按下态已在代码中设置，未专门捕捉瞬态截图；未测试其他分辨率、UI 缩放或多显示器布局。
