## 已定位问题，不在本轮修复

1. 建筑列表误识别自然物体。NativeInventoryCatalog.OwnerValid 仅检查实体存活/初始化和 BlockObject；AddBuilding 再检查 Inventories。树木和多肉植物也满足这些条件，因此混入列表。
2. 大量自然物体导致列表冗长，寻找仓库需要反复滚动。此次未出现可见卡死，但没有做量化性能测量，不能称大型聚居地性能合格。
3. 主动刷新会把资源下拉重置到第一项；读数更新有效，但交互不便。
4. 已完工中心的空施工库存可以被单独识别，但没有资源行时不显示容量明细；不能把这一空库存样本当作非空容量验证。

建议下一轮另行授权后做最小修复：依据已确认的原生建筑身份/组件排除自然物体，保留动态资源与多库存能力；补充“自然物体也有 BlockObject 和 Inventories”回归用例。不要改成原版建筑名称白名单。当前源码完全保留本轮待测版本，未自动修补。
