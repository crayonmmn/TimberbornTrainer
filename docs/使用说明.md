## 安装

基准环境：Windows64，Steam Timberborn1.1.2.8-ffc2de0-sw、Unity6000.5.11f1、Mono。使用官方Mod管理器，无需BepInEx、Harmony、其他Mod、Unity Editor或开发SDK。

退出游戏，备份旧Mod文件夹及存档，将 `TimberbornTrainer-v0.5.0-win64.zip` 解压到实际“文档”目录的 `Timberborn/Mods/`，注意OneDrive重定向。最终应有 `TimberbornTrainer/manifest.json`、同级DLL和 `Languages/en-US.json`、`Languages/zh-CN.json`。完整替换旧版文件夹，不混用v0.4.0中英文DLL；同ID `TimberbornTrainer.Core` 只装一份。备份放到Mods外，不把文件放入游戏Managed目录。

在官方管理器启用并按游戏提示重启，进入聚居地打开修改工具。每次加载时全局修改保持关闭，需手动开启。GitHub的Source code ZIP不能直接安装。下载[v0.5.0统一包](https://github.com/crayonmmn/TimberbornTrainer/releases/tag/v0.5.0)，历史v0.4.0保持可用。

## 语言设置

1. 没有有效手动偏好时，读取游戏当前语言：简体中文用zh-CN，英文、不支持或无法读取的语言用en-US。繁体中文不作为简体中文处理。
2. 在“界面语言”中选择English或简体中文。原窗口就地刷新，包括先前显示的操作结果和错误。游戏物品／建筑名称继续使用游戏本地化，ID不变。
3. 手动选择立即保存到 `%LOCALAPPDATA%/TimberbornTrainer/language.json`，以后优先使用，不被游戏语言覆盖。它与业务配置分离，不修改存档。保存失败会提示，本次会话仍可切换；退出游戏后仅移除该文件即可恢复自动选择。
4. 两份外置JSON使用UTF-8和一致键名。缺中文键先回退英文；英文也不可用时使用另一份可用资源或 `[Text unavailable: key]` 安全文本。文件丢失、损坏、重复键、无效UTF-8或过大都不应阻止启动。请从统一ZIP恢复两个文件，重启后重新加载；不提供文件监控或热编辑重载。
5. 切换语言不改变全局开关、暂停／速度、库存或科研，不重复执行命令，不清空输入、不移动或重建窗口。语言提示单独显示，不覆盖最后业务结果。

## 资源管理

在“物品库存”页直接选择地图上已完工、受支持的普通仓库，显示其已配置物品、当前量、容量和未预留可操作量。空仓库只要已在原生界面指定物品，也能操作。未指定物品、目标已拆除、库存身份不明确或用途不支持时，显示原因而不提供可写旧目标。

开启全局修改，再用游戏原生控制手动暂停。输入正整数后增加／减少。超过未预留容量或库存时整单拒绝并显示允许数量，不解除预留。执行后回读；异常可能发生在库存已变化之后，结果未确认时不要盲目重复点击。

支持通过原生物品服务注册的资源，但不保证所有自定义库存行为。道路／住宅的施工库存、生产缓冲及未知类型不会仅因存在Inventory组件就开放写入。聚居地总量是统计，不是可直接编辑的虚拟仓库。原有地区中心自身输出支持保留身份／归属限制；快捷地图页面用于支持的仓库。

科研点通过独立“科研点管理”入口访问原生科研服务，不是仓库物品。可刷新、增加10点、减少5点或设置目标，并对照原生界面。仅接受0至十亿的整数，减少不超过余额；需要全局开启，执行前校验，执行后回读。

## 建造与生产

点击“立即完成所有建造”一次，通过原生FinishNow处理当前符合条件的工地；之后新建工地仍正常施工。尊重建筑自身暂停、占位与验证器。反馈区分确认完成、受阻／未完成、跳过和异常／不确定；不自动重试或强制改完成标志，特殊工地可原生删除实体。

不提供生产倍率或额外材料返还／运输补丁。在途材料由原版物流安排。游戏整体暂停不是物流锁，此建造命令不要求必须暂停。

## 海狸管理

分别开启饥饿维持、口渴维持，再开启全局开关，恢复模拟后生效。对存活且初始化的海狸恢复原版正常满值，只暂停对应基础需求的自然更新，不锁定食物品种满足度等其他营养需求，也不强制取消已经开始的进食饮水／运输。

关闭单项或全局开关后归还原更新状态；通过原生人口与生命周期处理新增／失效海狸及卸载。运行异常会停止该场景维持并提示，不盲目继续。

## 窗口与配置

标题栏拖动，靠左右边缘吸附，鼠标离开后延迟隐藏。悬停／单击边缘标签唤醒，移动超过6个UI单位可单独拖标签，结束不自动打开。将完整窗口拖离边缘后保持展开，不跨启动记住坐标。普通区域保留原有WASD交互，输入框可编辑；用户报告本版功能正常，但并未穷尽所有字体、分辨率和Mod组合。

原保存／读取／导入／导出业务配置入口保留。读取和导入不自动开启全局修改或执行命令。语言偏好单独保存。遇无效输入、目标失效、读取失败或兼容警告，以界面反馈为准；警告不是对未验证版本的兼容保证。

## 兼容、卸载与常见问题

版本、Unity及接口诊断只警告，Windows64和原有业务条件保留。原生静态类型缺失可能在初始化或调用阶段失败，不承诺与所有第三方Mod兼容。

Mod不出现时检查官方启用状态、目录嵌套和重复ID。仓库不能编辑时检查完工、已指定物品、暂停、全局开关及具体原因。基础饥饿不下降但营养仍变化属于设计范围。文字不可用时恢复两份语言JSON，不要替换游戏DLL。

卸载前关闭持续维生和全局开关，退出游戏后仅移除本Mod文件夹。此前获得的库存／科研或已完成建筑不会撤销。本地偏好可单独保留或删除。
