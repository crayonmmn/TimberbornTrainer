# 第二阶段验收报告

日期：2026 年 11 月 7 日。版本：0.1.0。许可证：MIT，已由项目发起者确认。

## 实现范围

| 项目 | 结果 |
|---|---|
| 工程 | 独立官方 DLL 工作流；标准 netstandard2.1 csproj 与现有 Roslyn 构建脚本 |
| 加载入口 | TrainerMod 实现 IModStarter，公共无参构造；未安装或启动游戏验证 |
| 依赖注入 | 带 Game Context 的 Bindito Configurator，注册会话与 UI |
| 中文 UI | 五个模块入口、游戏和模组版本、全局状态、恢复默认、保存读取及导入导出 |
| 生命周期 | 场景 Load 创建 UI；Unload 解除状态订阅并移除 UI |
| 版本检测 | 精确检查游戏完整版本、Windows 64 位进程与 Unity 6000.5.11f1 |
| JSON 配置 | 版本、类型、重复及未知字段、数值范围、大小、深度、文件名校验；原子替换保存 |
| 全局状态 | 默认停用；加载或导入不会自动启用；环境不匹配不能有效启用 |
| 恢复默认 | 清除持续性偏好并恢复倍率与天气参数默认值，不回滚一次性修改 |

| Harmony | 没有引用或补丁 |
| 开源准备 | README、MIT LICENSE、.gitignore、完整源码和构建说明；未创建远程仓库 |

构建过程以本机目标版本游戏 Managed DLL 为元数据引用，不执行游戏程序集。

- Release 编译成功，零编译错误、零编译警告。
- 运行时源文件 12 个，另有测试源文件 1 个。
- 程序集：TimberbornTrainer，版本 0.1.0.0，18944 字节。
- 目标框架属性：.NETStandard,Version=v2.1。
- 元数据已确认 IModStarter、Game Context 与加载/卸载接口。
- 未引用 BepInEx、Harmony 或宿主的 System.Private.CoreLib。
- SHA-256：`5FAB39319D6598A3FE889A50C9A78288D31243CBF49B45A3409F1D43695C042C`。
- dist 包只含自有 DLL、manifest、README 与 MIT LICENSE。
- 标准 dotnet build 路径已提供，因未检测到 SDK，尚未验证。

## 测试结果

隔离文件目录中执行了 35 项配置、状态和版本检查断言，全部通过。
覆盖 JSON 往返、重复保存、非法范围、类型与版本、路径穿越、异常不覆盖原文件、
损坏配置、配置引用隔离、全局停用、默认恢复及环境不匹配保护。

这些测试在 PowerShell 的 .NET 运行时运行，未在游戏 Mono 中执行。
未使用用户存档或用户实际配置。测试产物位于 TestResults，已从公开源码包中排除。

## 未验证内容

- 官方加载器的实际发现与调用、Bindito 场景创建与卸载。
- 游戏内 UI 显示、字体、中文输入、点击和滚动、缩放及布局。
- 游戏 Mono 下的配置文件读写权限、原子替换与导入导出行为。
- 配置恢复对未来实际修改模块的作用；当前没有这样的修改模块。
- 四种建造组合、生产倍率、需求锁定和天气状态机，均未实现、未测试。
- 未配置完整 Unity Modding Tools 工程；此阶段使用官方文档允许的无 Unity DLL 工作流。
- 未运行 SDK/MSBuild 构建，未验证 macOS、Linux 或其他游戏版本。
