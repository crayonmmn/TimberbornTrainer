## 功能盘点

| 模块 | 分类及已证实范围 | 剩余事项 |
| --- | --- | --- |
| 聚居地资源统计 | 已实现只读统计，历史有样本；属于部分完成的物品管理 | 不是独立可注入库存；不把汇总当仓库 |
| 建筑库存、地区中心自身库存 | 部分实现，尚未达到完整可用/验收状态：有扫描、多库存与增减命令及历史实测样本；本轮补可达性、只读提示、失效与回读UI链路 | 非零输出预留、多地区隔离、第三方真实兼容等仍待实机；不支持施工/生产缓冲或独立库存系统写入，不能标为已完成 |
| 科研点数 | 原生服务/命令仍在；确认库存长内容挤压科研入口，本轮恢复独立入口并增加实际UI注册回调测试 | 必须实机确认新版入口、可读性、增减与原生数值同步，不将历史样本称为完整验收 |
| 饥饿维持 | 已实现但仍需验证：CharacterPopulation快照、正常Tick原生需求补偿、现有海狸枚举及基线计数、初始化/开关样本和替身回归 | 精确需求变化、独立关闭后的自然恢复、新生海狸及长期效果实测不足 |
| 口渴维持 | 已实现但仍需验证：与饥饿独立开关，相同生命周期保护 | 同上；不能把绿色需求条/清零基线当作全部效果已通过 |
| 一次性建造 | 已完成且经过验证：417项回归含32项命令测试；用户实测普通建筑、整体暂停、自身暂停限制、在途材料转送、无工地提示、新工地不自动完成和再次点击 | 特殊DeleteOnFinish工地、占位等阻挡、统计逐项原生对照、存档重载、无替代仓库及第三方仍待实机 |
| 生产倍率 | 已取消；ProductionMultiplier仅保留历史配置兼容 | 不恢复实现或UI |
| 高倍游戏速度 | 暂缓 | 不纳入本阶段 |
| 旧自动建造/独立免材料 | 已取消并替换为一次性命令，旧字段有效值关闭 | 不恢复旧逻辑 |

本轮未发现明确的新生产缺陷。依据：当前Modules/UI/Core和现有测试；实机证据见阶段四五开发记录、b500615第一轮实机记录、通用库存编辑实现与验收记录、库存预留与重载实机验收、一次性批量完工实现记录。只按对应样本定级，不把替身/纯逻辑测试扩展成游戏验收。

以上为历史盘点。当前仅保留资源管理、建造与生产、海狸管理三个模块；当前行为及限制以README和使用说明为准。
