## P2-B：拆除与失效验证

样本：空的小型材料堆，坐标(129,140,3)，原生模板SmallPile.Folktails，仓储Stockpile、资源Log，数量0/20。选择该样本是为了不拆食物或水供应建筑。拆除前通过列表选中并双击定位，原生面板和Trainer均确认原木0、空位20。

执行顺序及观察：

1. 主动扫描建立P2目录，计数1，98建筑、110库存、1中心。
2. 原生详情面板点击拆除，原生确认框明确显示将回收2原木；确认后建筑实体视觉消失，详情面板关闭，原位置出现瓦砾堆。不是仅添加拆除标记。
3. 保持旧扫描目录，点击“主动刷新”：扫描计数仍1，显示“目标已删除、替换或不再符合建筑身份，已清除该库存选择；请重新扫描”，旧库存和资源选择清除。
4. 打开缓存列表，旧快照仍含该材料堆；双击该项后仍提示失效，没有出现原生建筑详情、镜头错误移动或把其他建筑作为目标读取。该操作包含单击读取拦截，未独立证明双击Focus内部路径一定执行到了原生服务。
5. 主动扫描计数2，建筑97、库存108，材料堆从目录消失。没有自动把邻近木屋当成原目标。

**结果：通过该样本的删除后读取拦截、选择失效、旧项交互拒绝和重扫移除。** 缓存允许保存旧目录快照；实际读取并未信任该快照。
