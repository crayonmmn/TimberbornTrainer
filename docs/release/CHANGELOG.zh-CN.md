## 本版内容

- 中英文两个独立安装包，共用业务源码及Mod ID，只能安装其中一个，没有游戏内语言切换。
- 资源管理：地图选仓增减物品、独立科研点管理入口；保留原版容量、预留、暂停及有效目标检查。
- 建造与生产：一次性调用原版接口完成符合条件的现有工地，不持续自动施工，不提供生产倍率。
- 海狸管理：基础饥饿与口渴分别维持，关闭后恢复原有需求更新状态。
- 悬浮面板标题拖动、左右停靠、自动隐藏及边缘标签手势，不跨启动保存位置。
- 游戏版本、Unity版本和接口检查仅警告，不因为检查结果禁用功能；实际调用失败仍正常反馈，保留异常处理和不自动重试规则。
- 英文默认README、中文入口、双语使用说明、Fork及贡献说明；保留MIT许可证和第三方声明。

当前界面仅保留三个模块，不包含此前独立的天气／灾害控制。生产倍率仍已取消，高倍时间加速仍暂缓。
